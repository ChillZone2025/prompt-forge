## Standard Professional Approach for UX Research in SaaS & Product

Here's the industry-standard methodology for each component:

### **Interview Scripts**
**Structure:** Problem-Solution-Outcome framework
- **Opening:** Warm-up + consent (5 min)
- **Context:** Current workflow/pain points using behavioral questions (15 min)
- **Core:** Jobs-to-be-Done exploration with scenario-based probes (25 min)
- **Closing:** Future state desires + demographic capture (10 min)

**Best Practices:**
- Use "Tell me about the last time you..." for concrete examples
- Follow up with "What made that challenging?" for root causes
- Avoid leading questions; use neutral probes like "How so?" or "What else?"

### **Survey Design**
**Standard Architecture:**
- Screener questions → Core behavior questions → Attitudinal scales → Demographics
- Use validated instruments: SUS for usability, UMUX-Lite for UX, CES for effort
- 5-7 point Likert scales with neutral midpoint
- Branching logic based on user segments or usage patterns

**SaaS-Specific Elements:**
- Feature usage frequency matrices
- Churn risk indicators (NPS + usage satisfaction)
- Integration workflow complexity measures

### **Insight Synthesis**
**Three-Phase Process:**
1. **Affinity Mapping:** Cluster observations into themes using tools like Miro or Dovetail
2. **Pattern Identification:** Map themes to user journey stages and business metrics
3. **Insight Articulation:** Structure as "Users do X because Y, which impacts Z"

**Deliverable Standards:**
- Executive summary with 3-5 key insights
- Evidence-based recommendations prioritized by impact/effort
- User journey maps showing friction points
- Persona updates or behavioral segments

**Timeline Benchmark:** 2-3 weeks for qual synthesis, 1-2 weeks for quant analysis
