## PLANTED ISSUES (for evaluation — agent should catch these)

### Issue 1: RFI-007 Open 23 Days — Contract Violation and Delay Exposure
RFI-007 (structural beam conflict with HVAC duct) has been open 23 days with no response. The contract requires responses within 7 calendar days. This is a critical-path item — the contractor cannot install either the structural steel or the HVAC ductwork at this location until the conflict is resolved. At 23 days overdue, the contractor has legitimate grounds for a delay claim. Every additional day adds to the claim exposure. This RFI should have been escalated to the EOR and MEP engineer immediately and resolved with a coordination drawing or beam modification within the contractual timeline.

### Issue 2: Structural Steel Submittal Shows A36 Where Specs Require A992
The fabricator submitted shop drawings showing ASTM A36 steel (Fy = 36 ksi yield strength) where the specs require ASTM A992 (Fy = 50 ksi). This is not an acceptable substitution without structural engineering review. The EOR sized members based on A992's higher yield strength — using A36 means the members may be structurally inadequate (36 ksi is 28% lower yield than 50 ksi). The fabricator's claim that "A36 is the industry default" is incorrect — A992 has been the standard for wide-flange shapes since 2000. This submittal must be rejected or returned for EOR review. Approving A36 without engineering analysis could result in structural failure, and the reviewer who approves it shares liability.

### Issue 3: Fire Protection Submittal References Wrong NFPA 13 Edition
The sprinkler submittal is designed per NFPA 13-2016, but the project specs require NFPA 13-2022 (the edition adopted by California via CBC 2022). The contractor's claim that "density/area requirements haven't changed significantly" is misleading. The 2022 edition has updated requirements for healthcare occupancies including smoke compartment sprinkler coverage, obstruction rules, and storage protection criteria. HCAI (formerly OSHPD) will review the fire protection design and will reject calculations based on a superseded code edition. The submittal must be revised to the 2022 edition and recalculated. The contractor's hydraulic software needs to be updated — this is not an acceptable excuse for using an outdated code.

### Issue 4: Elevator Substitution Fails Energy Code
The contractor proposes substituting a single-speed AC motor for the specified VFD motor to save $8,000. However, the energy data shows the single-speed motor consumes 18,500 kWh/year vs. 11,100 kWh/year for VFD — a 67% increase in energy consumption (not the claimed "negligible" difference). More critically, ASHRAE 90.1-2019 Section 10.4.3 requires VFD or equivalent efficiency for elevators in buildings over a certain size. California's Title 24 energy code has similar requirements. This substitution would likely fail energy code compliance, which means it would fail plan check regardless of the owner's preference. The $8,000 savings is also misleading — at typical commercial electricity rates ($0.15/kWh), the VFD saves approximately $1,110/year, paying for itself in ~7 years, well within the elevator's 25-year service life. The substitution should be rejected on both code compliance and lifecycle cost grounds.

### Issue 5: Wall Covering Fails Class A Flame Spread — Fire Code Violation
The submitted vinyl wallcovering has a Flame Spread Index of 45 per ASTM E84 testing. The spec requires Class A (FSI ≤ 25). A Flame Spread Index of 45 is Class B, not Class A. In an I-2 (hospital) occupancy, interior finish requirements are among the most stringent in the building code — IBC Table 803.13 requires Class A or B for corridors and Class A, B, or C for rooms depending on sprinkler protection. However, the project spec explicitly calls for Class A (FSI ≤ 25), and more importantly, this is a patient care area where fire safety is paramount. The contractor's note that "this product is used in many healthcare facilities" may be true for non-patient-care areas, but the submitted fire test data clearly fails the specified requirement. This submittal must be rejected. Approving a non-compliant interior finish material in a hospital is both a code violation and a life-safety liability.
