## PLANTED ISSUES (for evaluation — agent should catch these)

1. **Fire code violation — occupancy exceeded:** The venue contract footnote (page 4) states maximum occupancy for the Grand Ballroom in banquet configuration is **380 persons** (including staff and vendors). The floor plan seats 400 guests, and the day-of staffing plan puts an additional 46 staff/vendors on the floor during peak service, for a total of **446 people** — exceeding the fire marshal limit by **66 persons**. This is not a minor issue — it's a fire code violation that could result in the event being shut down, fines for the venue, and personal liability for the event planner. The agent must catch this immediately and flag that the current plan is physically illegal.

2. **No allergen protocol for 400+ guests:** The menu includes shellfish (shrimp, prawn, crab, lobster) in 2 of 3 courses (first course and entrée option A). There is no pre-event dietary restriction collection — the plan states "kitchen will handle requests night-of." For a 400-person plated dinner, this is a serious liability exposure. Statistically, 2-3% of the US adult population has shellfish allergies (8-12 guests at this event). Without advance allergy collection, the kitchen cannot pre-prepare alternative plates, servers won't know which guests have allergies, and a guest could be served a plate containing their allergen. The agent must flag the need for a mandatory dietary restriction collection process during RSVP, pre-prepared allergen-free alternatives for all courses, and allergen labeling on table cards.

3. **Zero contingency budget:** The budget allocates every dollar with $0 for contingency. Industry standard for events of this scale is 10-15% contingency ($20,000-$30,000). With no buffer, any unplanned expense — vendor cancellation, equipment failure, weather affecting valet operations, additional AV needs discovered at rehearsal, extra tables/chairs, overtime labor — will blow the budget. The valet overflow parking ($1,200) is already identified as an unbudgeted cost. The agent must flag this as a fundamental planning failure and recommend reallocating budget or increasing the total to include contingency.

4. **A/V setup timeline is physically impossible:** The A/V vendor requires 3 hours for setup (load-in, rigging, testing) with sound check at 1:00 PM, meaning A/V load-in needs to start at 11:00 AM at the latest. But the venue contract states availability begins at **2:00 PM**. The A/V timeline document shows load-in at 11:00 AM — 3 hours before the venue is contractually available. If the venue enforces the 2:00 PM start, A/V setup would need to be compressed from 3 hours into the window between 2:00 PM and 6:00 PM (4 hours total), but that same 4-hour window must also accommodate: table setup and linen (40 rounds), floral/centerpiece placement (40 tables), bar setup (2 stations), registration desk, coat check, step-and-repeat backdrop, auction display, and all AV. This is physically impossible. The agent must flag the venue availability conflict and recommend either negotiating early access (additional cost) or restructuring the setup timeline.

5. **Severely understaffed for plated service:** The staffing plan shows 16 servers for 400 guests — a ratio of 1 server per 25 guests. For a black-tie plated dinner with 3 courses (not buffet), industry standard is **1 server per 10-12 guests** (33-40 servers for this event). At 1:25, each server must manage 25 covers across 3 plated courses plus wine service, water refills, and clearing. This means: first course plates will be cold by the time the last table is served, wine service will be inconsistent, clearing between courses will be slow (delaying the program), and the overall guest experience will feel rushed and understaffed — unacceptable for a $500/plate black-tie fundraiser. The agent must flag this staffing gap and recommend increasing server count to at minimum 34-40.
