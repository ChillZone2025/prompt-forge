## Competitive Landscape

### Direct Competitors

| Platform | Model | Size | Price | Key Weakness |
|----------|-------|------|-------|-------------|
| **PromptBase** | Marketplace (buy/sell individual prompts) | 260,000+ prompts | $1.99–$9.99 per prompt | No generation — static library. Buying one-by-one doesn't scale. |
| **AIPRM** | Browser extension (ChatGPT-focused) | Large library | $20/month | Locked to ChatGPT. Narrow scope. |
| **FlowGPT** | Community-driven free sharing | Millions of user submissions | Free | No quality control. Quantity over quality. Unusable noise. |
| **PromptHero** | Social network / gallery | Large | Free to browse | Focused on image prompts (Midjourney/DALL-E). Not agent-focused. |
| **God of Prompt** | Curated library | 30,000+ prompts | Subscription | Static library, not generated. Generic categories. |
| **TopFreePrompts** | Curated library | 50,000+ claimed | $10/month | E-commerce focused. Claims are unverified. |
| **Jasper** | AI writing suite with prompt library | 500+ prompts | Enterprise pricing | Marketing-only. Expensive. Not agent-focused. |

### What They ALL Have in Common (Their Weakness)
**None of them generate prompts.** Every competitor is a static library or marketplace where humans upload pre-written prompts. Users browse, buy, and copy-paste. If a prompt doesn't fit their exact use case, they're stuck.

## Strategic Implications for Agents

When creating new content, agents should always think through these lenses:

### 1. Fill Gaps Competitors Can't
Competitors can't easily add new industries because humans have to write every prompt. Prompt Forge can add an entire industry in minutes because the Claude API generates the content. **Speed of expansion is our moat.** The faster we grow the agent library, the harder it is for anyone to catch up.

### 2. Target Underserved Professional Audiences
The market research is clear: generic prompt categories (email writing, social media, basic productivity) are severely saturated. What retains value is **specialized domain knowledge for specific professional roles.** Every new industry and agent should target a real professional who would pay $12/month because the prompts save them hours.

### 3. Depth Over Breadth in Each Industry
Having 5 excellent, highly-specific agents per industry beats having 20 generic ones. Each agent should represent a real job function that a real person in that industry does daily. Think "Credit Risk Underwriter" not "Finance Helper."

### 4. Make the Free Tier a Taste, Not a Meal
3 free generates prove the product works but aren't enough to cover all your needs. Unlimited starter prompts remain free as a top-of-funnel asset. The gap between "this is amazing" (free) and "I need more" (Pro) should be exactly 3 clicks wide. Pro workspace features (refinement, version history, saved contexts, export) make the upgrade sticky — people stay because it's their prompt workspace, not just a generator.

### 5. Build Toward "First of Its Kind" Status
No one else generates deployment-ready agent system prompts organized by industry. Prompt Forge should own this category. Content expansion, SEO, and LinkedIn presence should all reinforce this positioning. When someone searches "AI agent prompts for [industry]," Prompt Forge should be the answer.

## Revenue Optimization Framework

When proposing new industries or agents, score them on:

| Factor | Weight | Question to Ask |
|--------|--------|----------------|
| **Willingness to Pay** | 30% | Would this professional easily justify $12/month to their boss or themselves? |
| **Frequency of Use** | 25% | Would they generate prompts weekly, or just once? Repeat usage = retention. |
| **Pain of Alternatives** | 20% | How hard is it for them to write these prompts from scratch? Higher pain = higher conversion. |
| **Market Size** | 15% | How many people hold this job title? Bigger pool = more potential subscribers. |
| **SEO Opportunity** | 10% | Are people actively searching for AI help in this industry? Low competition = easier ranking. |
